A little on .svg file:
SVG files are not HTML files; they are XML-based vector graphics files that can be embedded in HTML documents. SVG (Scalable Vector Graphics) is an XML-based format used to describe two-dimensional graphics, including shapes, paths, and text, in a resolution-independent way. Unlike HTML, which structures web content, SVG is specifically designed for graphics and can exist as a standalone file with a .svg extension or be embedded directly into an HTML document using the <svg> element.
